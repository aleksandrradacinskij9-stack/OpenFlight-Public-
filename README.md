# OpenFlight 2.0

**OpenFlight** — бесплатный авиасимулятор для Android, созданный сообществом.

## Лицензия

Проект распространяется под лицензией **PolyForm Noncommercial 1.0.0**.

## О проекте

Это вторая версия симулятора (2.0), разработанная с нуля с использованием современных AI-инструментов.

- **Язык:** C++17
- **Графический API:** Vulkan
- **Платформа:** Android (NDK)
- **Сборка:** CMake + Gradle
- **Текущая версия:** 0.06 (базовая физика, сцена и тестовый самолёт на Vulkan)

## Требования

- **Android Studio** (актуальная версия)
- **Android NDK** (Side-by-side)
- **CMake** 3.22.1+
- **Устройство с поддержкой Vulkan** (Android 7.0+ / API 24+)
- **Минимальная версия Android:** API 26 (Android 8.0)

## Как собрать

1. Установите **Android Studio** и **NDK** (через SDK Manager).
2. Клонируйте репозиторий командой: git clone https://github.com/aleksandradacinskii9-stack/OpenFlight-Public.git
3. Откройте проект в Android Studio.
4. Дождитесь окончания Gradle Sync.
5. Соберите APK через **Build → Build APK(s)**.
6. Установите APK на устройство с поддержкой Vulkan.
